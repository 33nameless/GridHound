# Численная фикстура лыжников

Содержит результаты модели на всех 358 кадрах предоставленного пользователем исходника, не фотографии и не видео. Данные получены в первоначальном диагностическом прогоне Assets/yolov8n.onnx из коммита 0ae4b8c. Вход 640×480; letterbox 114; RGB/255. Порог сохранения кандидатов 0,10; class-agnostic NMS 0,45. Ранее фикстура содержала только кандидатов от 0,45; в пакете восстановления включены уже сохранённые слабые кандидаты, повторного запуска другой модели не было.

Диагностический препроцессинг/постпроцессинг воспроизведён по C# на Python/OpenCV/ONNX Runtime CPU; побитовое совпадение с Windows не заявляется. Тест запускает реальные C# алгоритмы трекинга и выбора на этих данных. Время кадров исходника — f/24 секунд.

Первоначальный лыжник в ярких брюках: начальная рамка [383,718,37,96]. Начальный внутренний ID 3; красная куртка — ID 1; сосед в чёрном — ID 4. После дальнейшего движения внутренний ID выбранного лыжника может стать 11; пользовательский номер при этом сохраняется. Это не считается сменой личности только по изменению внутреннего номера.

Тесты проверяют восстановление после пересечения при шагах 1,2,4,8, отсутствие принятия известных соседних ID и сохранение номера. Дополнительный тест вручную уточняет правильную рамку f203 [169,841,53,98] и проверяет дальнейшее сопровождение на f240. Это программный вызов Rebind/Reanchor, не тест нажатий в WPF.

Общих метрик IDF1/MOTA по полной ручной разметке нет. Поздние потери при разреженных кадрах остаются известным ограничением.
