# Численная фикстура дорожного ролика

road-baseline-detections.json содержит ранее сохранённые обнаружения на 538 кадрах предоставленного дорожного исходника 3840×2160, 25 fps. Это не фото и не видео. Прежний диагностический прогон: Assets/yolov8n.onnx, вход 640×480, letterbox114, RGB/255, порог сохранения0,10, class-agnostic NMS0,45. Предобработка/постобработка воспроизведены на Python/OpenCV/ONNX Runtime CPU по логике приложения; побитовое совпадение с Windows не заявляется. Фикстура не содержит результатов seg-модели и не является независимой ручной разметкой.

Исходный удаляющийся автомобиль R: рамка f0[2940,1269,281,232]. Второй удаляющийся автомобиль B в плотном прогоне выбирается на f54[3075,1389,315,241]. R находится впереди B по ходу движения, выше и левее в изображении. Внутренние ID в диагностическом плотном прогоне1 и8; номера S назначаются отдельно и не должны зависеть от этих ID.

Тесты используют реальные текущие C# TrackerService/SelectionLogic: проверяют инициализацию R во всех восьми смещениях шага8, краткое восстановление того же ID, независимость двух S, отсутствие принятой рамки при отсутствии нужного обнаружения. Время кадров f/25, размеры кадра явно задаются при replay. Это не тест Windows GUI, режима планирования «Плавность», нового инференса или реального кодирования экспорта.

Данные и тесты не доказывают отсутствие всех переключений личности, точность на любых классах и сценах или полную длительность непрерывного сопровождения. В дальней части видео часть автомобилей видна человеку, но отсутствует среди сохранённых кандидатов модели — данный алгоритмический пакет не создаёт отсутствующие обнаружения.
